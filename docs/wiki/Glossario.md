# Glossario

I termini usati dal plugin e in queste pagine, con il termine inglese usato
nell'interfaccia in inglese.

| Italiano | English | Significato |
|---|---|---|
| appoggiatura | appoggiatura | Una dissonanza in tempo forte, raggiunta per salto o per grado, che si risolve per grado. Ammessa solo con le regole Libere. |
| cadenza | cadence | La conclusione di una frase; alla fine del brano il contrappunto arriva all'accordo di tonica per grado. |
| cambiata | cambiata | Dissonanza per grado, salto di terza nella stessa direzione, grado indietro (per esempio Do–Si–Sol–La sopra Do). |
| canto dato | cantus firmus | La melodia data, di solito in note lunghe, a cui si aggiunge un contrappunto. |
| consonanza (perfetta / imperfetta) | consonance (perfect / imperfect) | Un intervallo stabile: perfetta = unisono, quinta, ottava; imperfetta = terza, sesta. |
| contro-melodia, controcanto | counter-melody | Una seconda melodia scritta contro la prima. |
| culmine | climax | La nota più acuta di una linea, idealmente raggiunta una volta sola. |
| dissonanza | dissonance | Un intervallo teso: seconda, quarta (rispetto alla voce più grave), tritono, settima. |
| doppia volta | double neighbour | Le due note vicine di una nota, una dopo l'altra, poi il ritorno alla nota. |
| entrata in imitazione | imitative entry | Il contrappunto entra dopo la melodia ripetendone l'inizio. |
| falsa relazione | cross-relation | La stessa nota naturale in una voce e alterata in un'altra, a breve distanza. |
| contrappunto fiorito | florid counterpoint | La 5ª specie: un insieme delle altre, con ritmi vari. |
| grado congiunto / salto | step / leap | Un passaggio alla nota vicina della scala / un movimento più ampio. |
| imitazione | imitation | Una voce ripete un motivo di un'altra. |
| incrocio delle voci | voice crossing | Una voce più grave che sale sopra una più acuta. |
| intervallo | interval | La distanza tra due note. |
| intervallo delineato | outlined interval | L'intervallo tra l'inizio e il punto di svolta di un tratto nella stessa direzione. |
| moto contrario | contrary motion | Una voce sale mentre l'altra scende. |
| moto obliquo | oblique motion | Una voce si muove, l'altra tiene. |
| moto simile | similar motion | Le due voci vanno nella stessa direzione con intervalli diversi. |
| nota di passaggio | passing note | Una nota che riempie per grado un salto di terza. |
| nota di volta | neighbour note | Una nota a un grado di distanza che torna alla nota di partenza. |
| preparazione / risoluzione | preparation / resolution | La nota consonante prima di un ritardo / il grado in giù dopo. |
| quinte / ottave parallele | parallel fifths / octaves | Due voci che si muovono nella stessa direzione da una quinta a una quinta (da ottava a ottava). |
| quinte e ottave dirette (nascoste) | hidden (direct) fifths and octaves | Arrivare su una quinta o un'ottava per moto simile. |
| ritardo | suspension | Una nota tenuta mentre l'altra voce si muove, che diventa dissonante e scende di grado. |
| scambio delle parti | voice exchange | Il contrappunto del plugin che passa dall'altra parte della melodia quando non c'è spazio. |
| seme | seed | Il numero che identifica una variante. |
| sensibile | leading note (tone) | Il 7° grado, un semitono sotto la tonica, che tende a salire verso di lei. |
| specie | species | I tipi graduati di contrappunto di Fux: 1:1, 2:1, 4:1, ritardi, fiorito. |
| tempo forte / debole | strong / weak beat | I tempi accentati / non accentati della battuta. |
| tritono | tritone | La quarta eccedente (Fa–Si), tre toni interi. |
| voce | voice | Una linea melodica; anche le voci 1–4 di MuseScore su un rigo. |
