# Glossary

The terms used by the plugin and on these pages, with the Italian term used in
the Italian interface.

| English | Italiano | Meaning |
|---|---|---|
| appoggiatura | appoggiatura | A dissonance on a strong beat, reached by leap or step, that resolves by step. Allowed only with Free rules. |
| cadence | cadenza | The close of a phrase; at the end of the piece the counterpoint arrives on the tonic chord by step. |
| cambiata | cambiata | Dissonance by step, leap of a third in the same direction, step back (e.g. C–B–G–A over C). |
| cantus firmus | canto dato | The given melody, usually in long notes, to which a counterpoint is added. |
| climax | culmine | The highest note of a line, ideally reached once. |
| consonance (perfect / imperfect) | consonanza (perfetta / imperfetta) | A stable interval: perfect = unison, fifth, octave; imperfect = third, sixth. |
| contrary motion | moto contrario | One voice goes up while the other goes down. |
| counter-melody | contro-melodia, controcanto | A second melody written against the first. |
| cross-relation | falsa relazione | The same note natural in one voice and altered in another, close together. |
| dissonance | dissonanza | A tense interval: second, fourth (against the lowest voice), tritone, seventh. |
| double neighbour | doppia volta | The two neighbours of a note, one after the other, then the return to the note. |
| florid counterpoint | contrappunto fiorito | The 5th species: a mixture of the others with varied rhythms. |
| hidden (direct) fifths and octaves | quinte e ottave dirette (nascoste) | Arriving on a fifth or octave by similar motion. |
| imitation | imitazione | One voice repeats a motif of another. |
| imitative entry | entrata in imitazione | The counterpoint enters after the melody repeating its opening. |
| interval | intervallo | The distance between two notes. |
| leading note (tone) | sensibile | The 7th degree, a semitone below the tonic, which pulls up to it. |
| neighbour note | nota di volta | A note one step away that returns to the starting note. |
| oblique motion | moto obliquo | One voice moves, the other holds. |
| outlined interval | intervallo delineato | The interval between the start and the turning point of a run in one direction. |
| parallel fifths / octaves | quinte / ottave parallele | Two voices moving in the same direction from a fifth to a fifth (octave to octave). |
| passing note | nota di passaggio | A note that fills a leap of a third by step. |
| preparation / resolution | preparazione / risoluzione | The consonant note before a suspension / the step down after it. |
| seed | seme | The number that identifies a variant. |
| similar motion | moto simile | Both voices go the same way by different intervals. |
| species | specie | Fux's graded types of counterpoint: 1:1, 2:1, 4:1, suspensions, florid. |
| step / leap | grado congiunto / salto | A move to the next note of the scale / a larger move. |
| strong / weak beat | tempo forte / debole | The accented / unaccented beats of the bar. |
| suspension | ritardo | A note held while the other voice moves, which becomes dissonant and resolves down by step. |
| tritone | tritono | The augmented fourth (F–B), three whole tones. |
| voice | voce | One melodic line; also MuseScore's voices 1–4 on a staff. |
| voice crossing | incrocio delle voci | A lower voice going above a higher one. |
| voice exchange | scambio delle parti | The plugin's counterpoint crossing to the other side of the melody when there is no room. |
